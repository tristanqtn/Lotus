Lotus
by tristanqtn
v2.1.0

Lotus lives inside DevTools — open it to get started.

  1. 1
    Press F12 or Ctrl+Shift+I to open DevTools
  2. 2
    Click the Lotus tab (use >> overflow if hidden)
  3. 3
    Browse normally — requests appear automatically
Features
Auto-Capture All HTTP requests logged in real time
Full Capture Response bodies for POST/PUT/PATCH via debugger
Filter URL/method with regex + 2xx/3xx/4xx/5xx toggles
Modify & Resend Edit any request with side-by-side comparison
Diff Side-by-side diff of original vs modified request
Copy as cURL Export any request as a terminal command
Format Pretty/Raw toggle for JSON, XML, HTML, JS, CSS
Grouping Hierarchical view linking originals and modifications
Pause Temporarily stop capture without clearing history
